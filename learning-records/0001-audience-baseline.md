# Audience baseline: basic GitHub, no branches

The learners are data science students who can clone, add, commit, and push on a single `main` branch, but have never created or merged a branch. They are starting to use Claude Code for agentic coding. Lessons therefore start from "what is a branch" and must not assume knowledge of PRs, merges, CI, or worktrees.

**Implications:** Lesson 1 starts at the pointer model; every later lesson builds on the glossary terms introduced earlier; Claude Code material comes after the core branch → PR → CI loop is in place.
